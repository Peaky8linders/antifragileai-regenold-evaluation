R321–R326 is not ready to be described as fully verified. The pinned official EU AI Act corpus, local ontology/semantic assets, seed payload, and TurboQuant index pass their focused integrity suites, but the expanded review confirmed **4 Critical**, **16 Important**, and **3 Suggestion-level** defects. The deck names Loose/Strict scorecard axes but does **not** disclose their formulas. Local token/head metrics must therefore be described as proxies, not as the official metrics.

## Critical Issues

### [C1] Startup can overwrite a newer shared Aura graph from an older local seed

- **Files:** `app/main.py:276`, `app/main.py:546`, `app/main.py:588`, `scripts/seed_neo4j_kb.py:126`
- **Bug:** Auto-seed defaults ON whenever `NEO4J_URI` is present. A metadata timeout is converted to `meta_rows=[]` and starts the seeder; any seed-version mismatch also starts it without checking which version is newer. This repo ships `2026-07-24-r291-fullseed`, while the steering file records the shared Aura as `2026-08-08-r323-annex-sections`.
- **Impact:** A transient metadata delay or ordinary version skew can mutate the shared read-only graph with older node properties and metadata. This violates hard rule #12 and can silently lose the section/SubPoint behavior the updated graph is meant to provide.
- **Suggested fix:** Default auto-seed OFF in code; never seed after an unknown/timeout result; require an explicit writable-instance opt-in; reject downgrades; use read-only Aura credentials for this repo.
- **Confidence:** High (99%)
- **Found by:** Logic & Correctness, Error Handling, Contract & Integration, Security, Plan Alignment

### [C2] The local answer-correctness proxies can score a legal contradiction perfectly

- **Files:** `evals/bench/metrics.py:39`, `evals/bench/metrics.py:133`, `evals/bench/metrics.py:160`
- **Bug:** The deck says answer correctness is evaluated against question-specific ground-truth criteria, but the local axes are token Jaccard and token recall. The code removes `not` and `no` as stopwords. `The system is prohibited.` and `The system is not prohibited.` therefore produce identical token sets and score `1.0` on both Loose and Strict. Strict is one-sided recall and does not penalize extra hallucinated claims. The PDF does not support the code's claim that these formulas are competition-pinned.
- **Impact:** A feature can increase the named correctness score while making the legal holding false. These values cannot establish official answer-correctness improvement for R321–R326.
- **Suggested fix:** Rename the existing values as versioned diagnostic proxies. Create independently curated, official-text-backed per-question holdings and score actor, modality, negation, thresholds, exceptions, dates, and omissions explicitly. Keep semantic precision/recall diagnostics separate from the competition labels.
- **Confidence:** High (100%)
- **Found by:** Logic & Correctness, Contract & Integration, Concurrency/Security, primary reproduction

### [C3] The grounded answer judge is prediction-conditioned, permits unsupported claims, and clips the answer

- **Files:** `evals/judge/grounded.py:96`, `evals/judge/grounded.py:112`, `evals/judge/grounded.py:128`, `evals/judge/grounded.py:135`, `evals/judge/grounded.py:287`
- **Bug:** For answer correctness, the judge receives verbatim text selected from `gold_refs + pred_refs`. Official rows have 0% gold coverage, so the system's own references choose the supposed answer ground truth. The same prose can receive a different answer verdict when only its references change. The prompt passes when `incorrect == 0` and `missing == 0`, ignoring `unsupported`; aggregation also excludes unsupported assertions. Finally, only the first 1,400 answer characters are judged (1,200 for citation faithfulness).
- **Impact:** In the R325 grounded sample, three passing rows contained unsupported assertions, including `rg_035` with 2 correct and 6 unsupported assertions. Eight of 26 source answers exceeded 1,400 characters, so correctness-changing tails were invisible. Answer and reference axes are not independent, and neither is a complete-response score.
- **Suggested fix:** Select statutory context only from independent question labels; fail or resolve substantive unsupported assertions; judge the full wire answer or mark a clipped row unscorable; publish the prompt/metric version and judge-repeat agreement.
- **Confidence:** High (100%)
- **Found by:** Logic & Correctness, primary verification

## Correct Measurement Gate for the Improvement Targets

The official deck does not publish the Loose/Strict formulas, so no local implementation should claim formula equivalence. Use two layers:

1. **Competition contract gate:** send the exact OpenAI/LiteLLM history; require HTTP 200; exact three-key response with non-null strings/list; validate every full dotted coordinate and catalog existence; retain every requested row. Endpoint/empty/invalid-shape failures score zero.
2. **Independent gold:** for every question/turn, store atomic required holdings and exact minimal references, each linked to the pinned CELEX provision text and reviewed for actor, modality, negation, exceptions, thresholds, dates, and sub-points. Do not derive answer context from predicted references.
3. **Clearly named local proxies:** report criterion-level answer exact-pass, factual precision/recall/F1, and unsupported/contradicted/omitted counts; report reference contract validity, head recall, exact-coordinate precision/recall/F1, exact-set match, and actual-list minimality. Never label them official Ans/Ref Loose/Strict.
4. **Full-response judging:** reason over the complete wire answer. Unsupported substantive assertions fail unless resolved from independently selected official text. Keep answer and reference axes independent. Repeat judge calls or adjudicate disagreements; publish prompt/model/gold versions and agreement.
5. **Paired causal run:** same questions, recovered turn types, model, prompts, cache state, Aura seed/index manifest, and TurboQuant manifest for OFF/ON arms. Assert that vector/KG/parent-collapse features actually fired. Include easy, hard, ordinary follow-up, and adversarial-pushback strata.
6. **Decision rule:** require a positive paired lift with a bootstrap confidence interval on criterion answer correctness and exact-coordinate reference F1; no material regression in answer/ref strict exact-pass or head recall; zero invalid wire rows; and bounded answer/reference conciseness. Persist row-level evidence and the gate verdict.
