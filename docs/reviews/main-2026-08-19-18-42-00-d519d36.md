## Important Issues

### [I1] Dict-like dialogue objects crash Turn-1 root recovery on challenge turns
- **File:** `app/routes/regenold.py:7319-7332`
- **Bug:** Direct attribute accesses `dialogue[0].role` and `m.role.capitalize()` raise `AttributeError` when messages are dicts (standard in some FastAPI routes / test payloads) or when `content` is `None`. The outer exception handler silently catches this and falls back to noisy multi-turn concatenation instead of isolating the Turn 1 root question.
- **Impact:** Challenge turn intent recovery silently fails for dict-formatted message arrays.
- **Suggested fix:** Use safe dictionary/attribute extraction helpers with None-coalescing.
- **Confidence:** High (95%)
- **Found by:** Logic & Correctness Specialist, Error Handling & Edge Cases Specialist, Bug Verifier

### [I2] `extract_xml_channels` leaks `<answer>` tag on unclosed tags or attributes
- **File:** `app/security/prompt_guard.py:37-69`
- **Bug:** `_ANSWER_BLOCK_RE` strictly expects `<answer>(.*?)</answer>` with no attributes or internal whitespace. If an LLM response is token-truncated without `</answer>`, or has attributes like `<answer class="...">`, `.search()` fails and the fallback path leaves raw `<answer>` tags in `clean_answer`. Additionally, if multiple `<answer>` blocks appear (e.g. from prompt injection or quotes), `.search()` picks the first rather than the final generation.
- **Impact:** Raw XML tags leak into user-facing response prose, causing formatting and score degradation.
- **Suggested fix:** Support tag attributes/whitespace in regexes, extract the last `<answer>` match if multiple exist, and defensively strip remaining unclosed XML tags in fallback.
- **Confidence:** High (95%)
- **Found by:** Logic & Correctness Specialist, Error Handling & Edge Cases Specialist, Security Specialist, Bug Verifier

### [I3] Process-wide `os.environ` mutation in `_claude_max_enhance_answer` Bedrock fallback is not thread-safe
- **File:** `app/engines/_graph_rag_impl.py:9509-9533`
- **Bug:** Mutating `os.environ["REGENOLD_BEDROCK_MODEL"] = "claude-opus-4-6"` in a multi-threaded FastAPI / `ThreadPoolExecutor` environment causes race conditions where concurrent requests or background judge tasks observe overridden environment variables.
- **Impact:** Unpredictable model routing and cross-thread contamination during concurrent load or evaluation harness execution.
- **Suggested fix:** Pass `model_override: str | None = None` directly into `_bedrock_complete_for_graph_rag` instead of mutating process environment variables.
- **Confidence:** High (95%)
- **Found by:** Concurrency & State Specialist, Logic & Correctness Specialist, Bug Verifier

### [I4] Lookahead negation guard `_NEGATION_AHEAD_RE` fails on intervening words ("requirements", "obligations", "is therefore")
- **File:** `app/routes/regenold.py:4740-4747`
- **Bug:** `_NEGATION_AHEAD_RE` only allows parenthetical sub-points and commas between the provision mention and negation verbs. Natural legal phrases such as *"Article 50 obligations do not apply"* or *"Article 50 is not applicable"* fail the lookahead match and get promoted to wire citations.
- **Impact:** Inapplicable provisions are promoted as false positive wire citations in natural negative sentences.
- **Suggested fix:** Allow optional subject connectors (e.g. `obligations?|requirements?|duties|rules?|provisions?`, `is|are|would be`, `therefore|currently|automatically`) before the negation verb.
- **Confidence:** High (90%)
- **Found by:** Logic & Correctness Specialist, Bug Verifier
