## Critical Issues

### [C1] Import Shadowing & Missing Private Symbol Re-exports
- **File:** `app/engines/graph_rag/__init__.py:1-40`
- **Bug:** `from app.engines._graph_rag_impl import *` ignored private helper functions starting with `_` (`_detect_classification_topic`, `_retrieve_from_graph`, `_looks_structurally_truncated`, etc.) that are imported by `app/routes/regenold.py`, `logic_rag.py`, `fusion.py`, and 28 test modules.
- **Impact:** Downstream routes and pytest suites raised `ImportError` on collection.
- **Suggested fix:** Re-export all symbols from `_graph_rag_impl` dynamically via module `globals()` iteration in `app/engines/graph_rag/__init__.py`.
- **Confidence:** High (100%)
- **Found by:** Contract & Integration Specialist, Plan Alignment Specialist

## Important Issues

### [I1] Missing Deduplication Guards in `context_seeder.py` & `exemptions.py`
- **File:** `app/engines/graph_rag/retrieval/context_seeder.py:35` and `app/engines/graph_rag/risk_engine/exemptions.py:57-67`
- **Bug:** Repeated invocations of `enrich_context` or `evaluate_ast_exemptions` appended duplicate string entries to `context.bridging_context`, `context.ast_evaluations`, and `context.article_info`.
- **Impact:** Context bloat, duplicate prompt payload rendering, and skewed graph traversal statistics.
- **Suggested fix:** Add explicit membership / ID deduplication guards before appending to list attributes.
- **Confidence:** High (85%)
- **Found by:** Concurrency & State Specialist, Logic & Correctness Specialist

### [I2] Rigid Article Regex Matching in MedTech Seeder
- **File:** `app/engines/graph_rag/retrieval/context_seeder.py:27`
- **Bug:** Regex `rf"\barticle {art_num}\b"` missed short-form references like `"Art. 9"` or `"Art 9"`.
- **Impact:** Sectoral MedTech standards context (ISO 14971, IEC 62304) failed to bridge on common short-form questions.
- **Suggested fix:** Update regex to `rf"\b(?:article|art\.?)\s+{art_num_esc}\b"`.
- **Confidence:** High (85%)
- **Found by:** Error Handling & Edge Cases Specialist, Concurrency & State Specialist

### [I3] Silent Drop of Un-ID'd Obligations in Citation Extraction
- **File:** `app/engines/graph_rag/generators/citation_verifier.py:18-20`
- **Bug:** `oid = obl.get("id", obl.get("obligation_id", ""))` evaluated to empty string when obligations lacked explicit `"id"` keys, dropping valid citations.
- **Impact:** Missing citation nodes on wire responses for article obligations without explicit database UUIDs.
- **Suggested fix:** Provide fallback identifier extraction (`oid = obl.get("id") or obl.get("obligation_id") or obl.get("article") or obl.get("text", "")[:30]`).
- **Confidence:** High (80%)
- **Found by:** Logic & Correctness Specialist, Error Handling & Edge Cases Specialist
